# Paso 1 — Base del proyecto: Implementation Plan

> **DESCARTADO (2026-11-15):** el usuario decidió armar escenas y configuración a mano en el editor, guiado,
> sin scripts generadores. Se conserva solo como referencia de valores (PPU 32, 480×320, cuadrículas).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar el proyecto de Unity con todo el arte, audio y la fuente pixel importados con configuración pixel-perfect, y las 4 escenas (Title → Lobby → Floor ×3 → End) conectadas con botones y un GameManager persistente.

**Architecture:** El arte se copia una vez desde Godot y los scripts de Python se mudan a `Tools/ArtGen/` apuntando a `Assets/_Game/`. Un `AssetPostprocessor` aplica la configuración pixel solo a assets nuevos y corta las hojas según `sprite_grids.json`. El flujo de escenas vive en una clase estática `SceneFlow` sobre un `GameManager` que se crea antes de cargar cualquier escena.

**Tech Stack:** Unity 6000.6.9f1, URP 2D (Pixel Perfect Camera), uGUI + `Font` legacy para la fuente bitmap, Unity Test Framework (EditMode + PlayMode), Python 3 con Pillow/numpy.

**Spec:** `docs/superpowers/specs/2026-11-15-unity-migration-design.md`

    - `BackToTitle` → `ResetRun`, carga Title.
